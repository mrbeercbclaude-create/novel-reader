# Self-hosted Thai fonts

Downloaded from the official Google Fonts distribution on 2026-09-27.
No font request is made to Google at runtime.

- Noto Sans Thai variable font: https://github.com/google/fonts/tree/main/ofl/notosansthai
- Noto Serif Thai variable font: https://github.com/google/fonts/tree/main/ofl/notoserifthai
- Sarabun Regular and SemiBold: https://github.com/google/fonts/tree/main/ofl/sarabun

Noto fonts: Copyright 2022 The Noto Project Authors, https://github.com/notofonts/thai
Sarabun: see sarabun-OFL.txt for full copyright attribution.
Each family is distributed under the SIL Open Font License 1.1.
The corresponding original license files are included beside the fonts.
Font binaries are unmodified; the Noto filenames were shortened locally.
